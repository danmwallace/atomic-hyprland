# Hyprland Lua config port: design

Approved in conversation 2026-10-03. Supersedes the `hyprland.conf.j2` template in
`danmwallace.fedora.hyprland`; everything else in the role and the image stays as
designed in `2026-10-03-atomic-hyprland-design.md`.

## Why

Hyprland 0.56 (what the lionheartp COPR ships for Fedora 44 today) warns at every
session start that the `.conf` format is removed in 0.57. The role's whole desktop
config is a 330-line Jinja `.conf` template. Without a port, the first COPR build
of 0.57 produces an image whose Hyprland ignores the role's configuration. The
wiki now documents only the Lua format; there is no upstream converter.

Two smaller notices and one visual defect from the same session are folded in
because they touch the same files and the same release: `hyprland-guiutils` is
missing, the Waybar `custom/updates` module is an openSUSE leftover
(`checkupdates`, `zypper dup`) that renders a bare `0`, and every icon in Waybar,
Wofi and hyprlock is blank because the configs name `RobotoMonoNerdFontPropo`
and no Nerd Font is installed anywhere (Fedora does not package them).

## Facts verified 2026-10-03

| Fact | How |
|---|---|

| `Hyprland --verify-config` reports Lua errors with file and line (`attempt to call a nil value`, `stack traceback`) and prints `config ok` on success | same probe |

## Decisions

- **Port and trim.** The Lua config reproduces today's behaviour except: `$browser`
  becomes `firefox`; autostart drops `tailscale up`, the KTailctl and Vesktop
  Flatpaks, `xhost +SI:localuser` (no Xorg session), and the commented
  `swaync`/`nextcloud` lines; the duplicated layer-rule block and the commented
  window-rule examples are dropped. The three monitor rules for Dan's displays stay.
- **Split modules** (Hyprland's own recommendation): one short entry file and seven
  `conf/*.lua` modules, each `require`d in its own error scope.
- **Outright switch.** The role stops rendering `hyprland.conf` and `local.conf`.
  No dual-format period: 0.56 already prefers the Lua file.
- **Font in the role**, not only the image: the role's Waybar, Wofi and hyprlock
  templates depend on it, so any host running the role needs it.
- **Transitional 0.56 pin in the image only**, removed by the commit that lands the
  port. The role never pins Hyprland.

## File layout (rendered under `{{ hyprland_home_dir }}/.config/hypr/`)

```
hypr/
  hyprland.lua          entry: palette table, require("conf.<module>") x7, pcall(require, "local")
  conf/
    monitors.lua        hl.monitor(...) x4
    autostart.lua       hl.on("hyprland.start", ...) with hl.exec_cmd per command
    env.lua             hl.env(...) x11
    look.lua            hl.config({ general, decoration, dwindle, master, misc, cursor }),
                        hl.curve(...) and hl.animation(...) per line of today's animations block
    input.lua           hl.config({ input, gestures }), hl.gesture(...) x3, hl.device(...)
    binds.lua           every hl.bind; workspace binds generated by a for loop
    rules.lua           hl.workspace_rule x3, hl.layer_rule x3
  local.lua             per-machine overrides; created once (copy with force: false), never managed
  hyprlock.conf         unchanged
  scripts/sleep.sh, xdg-portal-hyprland   unchanged
```

Templates in the role: `templates/home/config/hypr/hyprland.lua.j2` and
`templates/home/config/hypr/conf/<module>.lua.j2`. Only `hyprland.lua.j2`
(palette), `autostart.lua.j2` (`hyprland_wallpaper`) and `monitors.lua.j2`
carry Jinja; the rest are plain Lua that reads the global `palette` table.
`hyprland.conf.j2` is deleted. The directory task list gains `hypr/conf`.

### Entry file

```lua
-- {{ ansible_managed }}
palette = {
  name            = "{{ hyprland_palette.name }}",
  cursor_theme    = "{{ hyprland_palette.cursor_theme }}",
  bg_darkest      = "{{ hyprland_palette.bg_darkest }}",
  -- one line per key in vars/themes/<theme>.yml, hex without '#'
}

require("conf.monitors")
require("conf.autostart")
require("conf.env")
require("conf.look")
require("conf.input")
require("conf.binds")
require("conf.rules")

-- Per-machine overrides (VM monitor, NVIDIA env, ...). Never managed.
pcall(require, "local")
```

Colour strings are built in Lua: `"rgba(" .. palette.accent_primary .. "ee)"`.
The gradient border is `{ colors = { "rgba(..ee)", "rgba(..ee)", "rgba(..ee)" }, angle = 45 }`.

### Construct mapping

| `.conf` today | Lua |
|---|---|
| `monitor=desc:BOE 0x0BCA,2256x1504@60.00Hz,auto-left,2` | `hl.monitor({ output = "desc:BOE 0x0BCA", mode = "2256x1504@60", position = "auto-left", scale = 2 })` (and the LG, Pixio and `preferred,auto,auto` fallback rules) |
| `$terminal = alacritty` etc. | `local terminal = "alacritty"` in the module that uses it; `browser = "firefox"` |
| `exec-once = X` | `hl.exec_cmd("X")` inside the `hyprland.start` handler, same order |
| `env = NAME,value` | `hl.env("NAME", "value")`; `HYPRCURSOR_THEME` from `palette.cursor_theme` |
| `general { ... }` and the other option blocks | keys of one `hl.config({...})` table; `col.active_border` becomes `col = { active_border = {...}, inactive_border = "rgba(..aa)" }` |
| `bezier = name, a, b, c, d` | `hl.curve("name", { type = "bezier", points = { {a, b}, {c, d} } })` |
| `animation = leaf, on, speed, curve[, style]` | `hl.animation({ leaf = "leaf", enabled = true, speed = N, bezier = "curve", style = "..." })` |
| `gestures { ... }` | `hl.config({ gestures = {...} })` |
| `gesture = 3, horizontal, workspace` / `3, down, mod: ALT, close` / `3, up, mod: SUPER, scale: 1.5, fullscreen` | `hl.gesture({ fingers = 3, direction = "horizontal", action = "workspace" })` / `{ fingers = 3, direction = "down", mod = "ALT", action = "close" }` / `{ fingers = 3, direction = "up", mod = "SUPER", scale = 1.5, action = "fullscreen" }` |
| `device { name = X; sensitivity = -0.5 }` | `hl.device({ name = "X", sensitivity = -0.5 })` |
| `bind = $mainMod, T, exec, $terminal` | `hl.bind(mod .. " + T", hl.dsp.exec_cmd(terminal))` with `local mod = "SUPER"` |
| `bind = $mainMod SHIFT, V, exec, <pipeline>` | key `mod .. " + SHIFT + V"`, the pipeline string unchanged |
| `bindl` / `bindel` / `bindm` | flags `{ locked = true }` / `{ locked = true, repeating = true }` / `{ mouse = true }` |
| `bindl = , switch:on:Lid Switch, exec, hyprctl keyword monitor "eDP-1, disable"` | `hl.bind("switch:on:Lid Switch", hl.dsp.exec_cmd("hyprctl keyword monitor 'eDP-1, disable'"), { locked = true })`; same for `switch:off` |
| `killactive` / `togglefloating` / `fullscreen 0` / `fullscreen 1` / `pseudo` / `layoutmsg togglesplit` / `exit` | `hl.dsp.window.close()` / `hl.dsp.window.float({ action = "toggle" })` / `hl.dsp.window.fullscreen(0)` / `hl.dsp.window.fullscreen(1)` / `hl.dsp.window.pseudo()` / `hl.dsp.layout("togglesplit")` / `hl.dsp.exit()` |
| `movefocus l` (and r/u/d, arrows and hjkl) | `hl.dsp.focus({ direction = "left" })` |
| `movewindow l` | `hl.dsp.window.move({ direction = "left" })` |
| `resizeactive -20 0` | `hl.dsp.window.resize({ ... })` with the pixel delta in the form the stub's `@param` documents |
| `workspace N` / `movetoworkspace N` / `movetoworkspacesilent N` for 1..10 | `for i = 1, 10 do local key = i % 10; hl.bind(mod .. " + " .. key, hl.dsp.focus({ workspace = i })); hl.bind(mod .. " + SHIFT + " .. key, hl.dsp.window.move({ workspace = i })); hl.bind(mod .. " + CTRL + SHIFT + " .. key, hl.dsp.window.move({ workspace = i, silent = true })) end` |
| `workspace e+1` / `e-1` (Super+scroll and Ctrl+arrows) | `hl.dsp.focus({ workspace = "e+1" })` |
| `togglespecialworkspace magic` / `movetoworkspace special:magic` | `hl.dsp.workspace.toggle_special("magic")` / `hl.dsp.window.move({ workspace = "special:magic" })` |
| `bindm mouse:272 movewindow` / `mouse:273 resizewindow` | `hl.dsp.window.drag()` / `hl.dsp.window.resize()` with `{ mouse = true }` |
| `workspace = w[t1], gapsout:0, gapsin:0, border:false, rounding:false` | `hl.workspace_rule({ workspace = "w[t1]", gaps_out = 0, gaps_in = 0, border = false, rounding = false })` |
| `layerrule = blur on, match:namespace waybar` | `hl.layer_rule({ match = { namespace = "waybar" }, blur = true })` |
| `source = ~/.config/hypr/local.conf` | `pcall(require, "local")` |

Two argument shapes are not fully pinned by the wiki excerpts read during design:
`hl.dsp.window.resize` with pixel deltas and `hl.dsp.window.fullscreen`'s mode
argument. The implementer confirms both against the `@param` lines in
`/usr/share/hypr/stubs/hl.meta.lua` before writing `binds.lua`; `--verify-config`
is the check.

## Folded-in changes

**Nerd Font (role).** New variables `hyprland_nerd_font_url` (default the v3.5.1
RobotoMono URL above), `hyprland_nerd_font_checksum` (`sha256:61f5...8383`), and
`hyprland_nerd_font_dir` (`/usr/share/fonts/roboto-mono-nerd`). Tasks:
`ansible.builtin.get_url` with `checksum` to `/tmp/RobotoMono.tar.xz` (only when
the marker file is absent), `ansible.builtin.unarchive` into the dir with
`creates: <dir>/RobotoMonoNerdFontPropo-Regular.ttf`, and `fc-cache -f` notified
only when extraction changed something. Second run: no changes.

**hyprland-guiutils (role).** Added to the package list.

**Waybar (role).** `custom/updates` removed from `modules-left` and its definition
deleted from `config.j2`.

**sync-dotfiles (image).** The create-once rule targets `.config/hypr/local.lua`;
the manifest exclusion and the test case follow. Existing `local.conf` files are
neither synced nor removed.

**Transitional pin (image).** `build/packages.txt` gains `hyprland-0.56*` in the
commits before the port lands and loses it in the commit that pins role 1.2.0.

## Testing

**Molecule (both scenarios' verify):** `hyprland.lua`, the seven `conf/*.lua`,
`local.lua` exist; `hyprland.conf` does not exist under the rendered tree; the
palette's primary accent hex appears in `hyprland.lua`; the Nerd Font Propo
Regular file exists. The skel scenario also runs
`HOME=<tmp> Hyprland --verify-config --i-am-really-stupid` against a copy of the
rendered tree and asserts exit 0 and `config ok` in the output. Idempotence must
pass (font task uses `creates:`).

**Image smoke test:** copy `/etc/skel/.config/hypr` into a temp HOME, run
`Hyprland --verify-config --i-am-really-stupid` **without** `--config` so
Hyprland's own file selection picks `hyprland.lua`; require exit 0, a `config ok`
line, and no line matching `attempt to|stack traceback|Config error`. Also:
`test ! -e /etc/skel/.config/hypr/hyprland.conf`, `rpm -q hyprland-guiutils`,
`fc-match -f '%{family}' RobotoMonoNerdFontPropo` contains `Nerd Font Propo`.
`test-sync-dotfiles.sh`'s pre-existing-home case asserts `local.lua`.

**VM acceptance:** `bootc status` on the new build; `Hyprland --verify-config` as
`dwallace` prints `config ok`; a graphical login shows no notification banners,
Waybar icons render; Super+T, Super+Space, Super+C, Super+arrows, Super+1..5 and
Super+L behave as before. Everything up to the login is verified over SSH; the
last items are Dan's at virt-viewer.

## Release and rollout

1. Role 1.2.0: templates, tasks, defaults, argument_specs, README, CHANGELOG
   (Changed: Lua config, local.lua; Added: font vars, guiutils; Removed:
   hyprland.conf, local.conf, Waybar updates module). PR, CI, merge, tag.
2. Image: `build/requirements.yml` to v1.2.0, remove the 0.56 pin, rebuild,
   `just test`, push.
3. VM: `sudo bootc upgrade` and reboot; the sync unit refreshes managed files at
   login and creates `local.lua`; re-enter the VM's three `local.conf` lines into
   `local.lua` (this becomes the README example):

   ```lua
   hl.monitor({ output = "Virtual-1", mode = "preferred", position = "auto", scale = 1 })
   hl.config({ cursor = { no_hardware_cursors = true } })
   hl.env("WLR_RENDERER_ALLOW_SOFTWARE", "1")
   ```

4. Rollback: `bootc rollback` on the VM; role 1.1.2 stays on Galaxy and the image
   pins by tag.
